# Welcome to Logi Actions SDK

Here you can find an introduction to Logi Actions SDK, example plugin source code and the SDK documentation. 

## Demo Plugin Features

The DemoPlugin includes examples of various Loupedeck plugin capabilities:

### Dynamic Commands
- **ThumbUpDownCommand**: Toggle between thumbs up and thumbs down icons
- **ButtonSwitchesCommand**: Multiple button switches with parameter support
- **ToggleMuteCommand**: System volume mute control

### Dynamic Adjustments
- **CounterAdjustment**: Rotary dial counter with reset functionality

### Application Integration

#### macOS Finder Toolbar
A comprehensive dynamic toolbar for macOS Finder with the following commands:
- **New Window**: Opens a new Finder window (⌘N)
- **New Folder**: Creates a new folder (⌘⇧N)
- **Move to Trash**: Moves selected items to trash (⌘Delete)
- **Get Info**: Shows info for selected items (⌘I)
- **Quick Look**: Preview selected items (Space)
- **Go Back**: Navigate to previous folder (⌘[)
- **Go Forward**: Navigate to next folder (⌘])
- **View Options**: Show view options (⌘J)
- **Duplicate**: Duplicate selected items (⌘D)

The Finder toolbar is automatically activated when Finder is the active application on macOS.
